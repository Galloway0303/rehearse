# Product walkthrough (~8 minutes)

A suggested path for demos or first-time evaluation.

## Prep

1. Run `npm run electron:dev` or a packaged build on Windows.  
2. Optional: add an xAI API key in Settings (offline template drills work without a key).  
3. Use a single primary display when possible.

## Script

### 1. Language & product one-liner (30s)

- Launch **Rehearse**.  
- Toggle **EN / 中文**.  
- One-liner: *“Not a site plugin — a screen-level learning loop.”*

### 2. Onboarding or Demo (1 min)

- First run: region (or skip via Demo), freedom **Standard**, API optional.  
- From Home: **Start demo stream**.

### 3. Chinese friction (1.5 min)

- Show mask / delayed Chinese while English remains usable.  
- Hotkey **Ctrl+Shift+F** — flash Chinese.  
- **Ctrl+Shift+L** — cycle levels; show Strict.

### 4. Capture words (1.5 min)

- Enable word assist if needed; click target words.  
- Show toast + **Undo**.  
- Open **Vocab** — context sentences attached.

### 5. End episode & rehearse (2–3 min)

- **End Episode** (`Ctrl+Shift+E`).  
- **Generate rehearse drills**.  
- Answer 2–3 questions; show reveal sentence + “why this word”.  
- If no API key: offline templates still close the loop.

### 6. Privacy note (30s)

- Settings: local data, optional AI, clear all data.
